# TinySAT

勉強目的でSATsolverの自作をする。

## 現状:

任意の命題論理式をS式で記述したものを受取り、字句解析と構文解析してAST木を構築します(10/10)

AST木を元に、命題論理式を評価する関数を追加しました(10/12)

真理値割り当てをv形式で読み取る関数を追加しました。ただし長さがめんどうなので、

```
n v1 v2 v3 ... vn
```

という形式で受け取るように暫定的になっています。ゆくゆくはASTから変数のnameの最大値を探して、それを配列の要素の最大とするように改善します。(10/13)

DPLLを実装しました。SAT/UNSATの判定ができます。(10/17)
